## Overview
Prutor-DSA is a collection of Data Structures and Algorithms (DSA) solutions in C++ and Python, designed to help students and professionals practice and improve their coding skills. The project provides a comprehensive set of problems, along with their solutions, to aid in the learning process.

## Features
* Comprehensive collection of DSA problems and solutions
* Multiple programming languages supported (C++ and Python)
* Well-structured and readable code
* Easy to navigate and use

## Tech Stack
* Programming languages: C++, Python
* Development environment: Visual Studio Code (VS Code)
* Version control: Git

## Architecture
The project is organized into multiple directories, each representing a different lab or set of problems. Each lab directory contains a set of problem files (e.g., `que1.cpp`, `que2.cpp`, etc.) and a `main.py` file, which is used to generate the problem files.

The project structure is as follows:
```markdown
prutor-DSA/
├── Lab 2/
│   ├── .vscode/
│   ├── input.txt
│   ├── main.py
│   ├── output.txt
│   ├── que1.cpp
│   ├── que2.cpp
│   ├── ...
├── Lab 3/
│   ├── .vscode/
│   ├── input.txt
│   ├── main.py
│   ├── output.txt
│   ├── que1.cpp
│   ├── que2.cpp
│   ├── ...
...
```
## Getting Started
### Prerequisites
* C++ compiler (e.g., GCC)
* Python interpreter (e.g., Python 3.x)
* VS Code (optional)

### Installation
1. Clone the repository: `git clone https://github.com/xevrion/prutor-DSA.git`
2. Navigate to the project directory: `cd prutor-DSA`
3. Install required dependencies: `pip install -r requirements.txt` (if using Python)

### Configuration
* No configuration is required for this project.

## Usage
1. Navigate to the desired lab directory: `cd Lab 2` (e.g.)
2. Run the `main.py` file to generate the problem files: `python main.py`
3. Open the generated problem files (e.g., `que1.cpp`) and start coding!
